# CampusBud

A responsive academic dashboard designed to help students manage their college life in one place.

## Features

- 📅 Daily timetable
- 📝 Assignment tracking
- 📊 Attendance tracking
- 📚 Exam scheduling and results
- 🎓 SGPA and CGPA tracking
- 📱 Responsive design
- 💾 Data persistence with localStorage

## Built With

- HTML
- CSS
- JavaScript
- Google Fonts

## About

CampusBud was created as a personal project to build a practical tool for managing academics while developing my front-end web development skills.

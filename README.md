*CampusBud*

A responsive and accessible academic dashboard designed to make college life a little easier by bringing everyday academic tasks into one place.

Your academic companion, from the first day of college onward.

*Features*

* 📅 Daily timetable
* 📝 Assignment tracking
* 📊 Attendance tracking
* 📚 Exam scheduling and results
* 🎓 SGPA and CGPA tracking
* 📱 Responsive design across screen sizes
* ♿ Accessibility-focused interface
* 💾 Persistent data storage with `localStorage`

*Built With*

* HTML
* CSS
* JavaScript
* Google Fonts

*Accessibility & Responsive Design*

CampusBud was designed to be usable across different devices and by as many users as possible.

* Responsive layouts for desktop, tablet, and mobile screens
* Semantic HTML structure
* Clear visual hierarchy and readable typography
* Accessible form elements and navigation
* Keyboard-friendly interactions where applicable
* Responsive components that adapt to different screen sizes

*The Idea*

I believe a first project should solve a problem you actually have—or at least make your work a little easier.

After all, great ideas often begin with a simple need: the bulb because we needed light after sunset, the clock because we needed to measure time, and AI because apparently humans eventually decided that some tasks were *way* too boring to do themselves.

CampusBud started from a similar problem.

The idea first came to me before I had even started college. I wanted something that could help me stay organized and make the transition into college life a little easier. So instead of waiting for the perfect tool to exist, I decided to build one myself.

*Why "CampusBud"?*

The name has two meanings.

**Bud** is short for *buddy*—because I wanted CampusBud to feel like a companion throughout college.

It also represents a **bud**, an unbloomed flower. Starting college is a little like that: you arrive with plenty of potential, but there's still a lot of growing, learning, and figuring things out ahead.

*Where It Is Now*

CampusBud is currently built around my own academic workflow and needs. It isn't intended to be a fully-fledged platform for other students yet.

There is still plenty of room for it to grow. Some of the things I hope to explore in the future include:

* 🔐 User authentication and individual accounts
* 🗄️ A proper backend and database
* ☁️ Cloud-based data storage
* 👥 Support for multiple students
* 📈 More advanced academic insights
* ⚙️ More customization and personalization

I'm treating CampusBud as both a useful tool and a learning project. As I learn more about full-stack development, databases, authentication, and application architecture, I hope to use those skills to gradually turn CampusBud from a personal dashboard into something that can genuinely help other students too.


*Project Status*

Currently: Front-end MVP / personal academic dashboard

CampusBud is an ongoing project. The current version focuses on creating a practical, responsive, and accessible interface while I continue learning the technologies needed to build the next stage of the application.
